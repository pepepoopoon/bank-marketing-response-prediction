# Журнал воспроизводимых экспериментов

В каталоге `results` находится 81 фактически выполненный запуск на синтетических
хронологических данных. Каждый JSON содержит полную конфигурацию, SHA-256 набора,
размеры и доли классов по временным окнам, validation-сравнение кандидатов,
test-метрики выбранной модели и dummy baseline, временную динамику и сегментные срезы.

## Серии запусков

- 5 опорных запусков;
- 12 точек зависимости качества от контактного бюджета;
- 16 повторов для оценки устойчивости к зерну модели;
- 12 точек кривой обучения от 90 до 840 строк;
- 12 сравнений раннего и позднего test-окна;
- 15 абляций пяти групп признаков;
- 9 сценариев качества данных: числовые пропуски, новая категория и смешанные пропуски.

Контактный бюджет менялся от 5% до 50%. В 63 из 81 запусков PR-AUC выбранной модели
оказался выше dummy baseline. Медиана PR-AUC по неоднородным сценариям составила
0,0772, диапазон — от 0,0264 до 0,2845. Эти числа нужны для проверки поведения
pipeline и не являются оценкой качества на реальной банковской кампании.

Выбор модели по validation распределился так: weighted logistic regression — 22 раза,
logistic regression — 20, calibrated random forest — 16, random forest — 12,
gradient boosting — 11. Это подтверждает, что runner действительно переобучает и
сравнивает кандидатов, а не копирует заранее подготовленный результат.

## Воспроизведение

Пример повторного запуска без перезаписи существующего результата:

```bash
PYTHONPATH=src python -m bank_marketing.experiments \
  --experiment-id example-budget-15 \
  --output /tmp/example-budget-15.json \
  --rows 420 \
  --data-seed 20250720 \
  --model-seed 20250719 \
  --budget-fraction 0.15
```

Для абляций используется `--ablation`, для проверок качества данных —
`--data-quality`. Runner отказывается перезаписывать существующий JSON, поэтому
каждый сохранённый результат соответствует отдельному запуску.
