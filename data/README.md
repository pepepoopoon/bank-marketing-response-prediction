# Данные

Источник из `projects.md` — [UCI Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank%2Bmarketing). Перед использованием проверьте лицензию и условия распространения на странице UCI. Исходные данные здесь не публикуются.

Используется схема `bank-additional-full`: загрузчик распознаёт запятую или `;` и сохраняет исходный порядок строк для приближённого временного split. Поле `duration` разрешено во входе, но всегда исключается: оно становится известно только после звонка и является утечкой для решения до контакта.

`make smoke` создаёт детерминированный **синтетический smoke-набор** без реальных клиентов. Он предназначен только для проверки исполнения.
